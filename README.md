# 元宝地雷 · 猜数字桌游(真心话大冒险版)

数字 1~100 里藏着一个「元宝」和与它相邻的「地雷」。大家循环轮流猜数字,猜的数会把范围向自己这边收窄,直到有人踩中元宝或地雷——踩中元宝得奖励,踩中地雷受惩罚,惩罚/奖励都是随机真心话或大冒险。

## 玩法规则

1. **开局设置**:每局范围 1~100,随机藏一个元宝(也可自定义),地雷必须与元宝相邻(±1),每局都不一样。
2. **轮流猜数**:人数不限,循环轮流。猜的数必须在当前范围内。
3. **范围收窄**:猜的数落在范围下半段 → 成为新下界(如猜 25 → 范围 25~100);落在上半段 → 成为新上界(如再猜 85 → 范围 25~85)。
4. **保护机制**:猜的数若会把元宝/地雷排除出范围,会被拒绝,保证游戏必然结束。
5. **胜负结算**:踩中元宝 → 奖励:赢家可随机指定一位参与者完成真心话或大冒险;踩中地雷 → 惩罚:本人随机抽真心话或大冒险。

## 两种玩法形态

### 1. 面对面版(浏览器直接玩,无需服务器)
打开 `public/face-to-face.html`,一台设备大家轮流点,输入昵称 → 开局 → 轮流猜。

### 2. 微信联机版(朋友各自手机玩)
- 服务器:`node server/server.js`(端口 `process.env.PORT` 或 3000)
- 客户端:浏览器访问服务器地址,输入昵称创建房间,把房间码或链接发给微信朋友,朋友加入后即可开玩。
- 依赖安装:`npm install`
